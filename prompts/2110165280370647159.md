## Prompt

```text
架空の海賊船（17世紀のガレオン船風・3本マスト・船名なし）が、

羊皮紙の図面から組み上がって夕暮れの海へ出航するアニメーションを、

Three.js のWebページとして作ってください。最後に MP4 にも書き出してください。

【形】船の寸法・部品・組み上がる順番とタイミングは、設計書（データ1つ）にまとめる。

  船体（なめらかな曲面）、肋材、甲板、船尾楼と船首楼、大砲22門と赤い砲門、

  3本のマストと帆桁、索具（縄ばしご付き）、横帆6枚＋三角帆＋斜檣帆、

  金の飾り、船尾の窓と角灯、船首像、ドクロ旗と吹き流し。

【流れ】約20秒＋ロゴ3.5秒、音つき。

  1. 羊皮紙の巻物が上から広がり、セピアの甲板平面図が現れる（方位盤・題字・封蝋つき、真上から）

  2. 図面の線が光る線として立ち上がる

  3. 竜骨 → 肋材 → 外板（下から1段ずつ張られる）→ 甲板 → 大砲 → マスト → 帆桁 → 索具 → 帆

     → 金の飾り・角灯・旗の順に組み上がる（カメラは船に寄る）

  4. 紙が消え、下から海が満ちて船が浮かぶ。夕焼けの空が現れ、カメラは引く

  5. 角灯がともり、帆が風をはらんで進み出す（波に揺れ、旗がはためく）

  6. 右舷の大砲が三発 → タイトル「海賊船」→ 最後に指定のロゴ

  音は外部素材を使わず Python で合成する（船乗りの歌・木槌・波・かもめ・大砲）。

【ページの機能】

  - 再生／一時停止、スライダーで好きな場面へ移動、今の場面名を表示、音と映像を同期

  - 自動カメラと自由カメラ（マウスで船の周りを回せる）の切り替え

  - 空は Three.js の Sky に夕焼けの色を重ね、海は Water で船を映す。光るものにはブルーム

【MP4 書き出し】

  ページに書き出しモードを付け、1920×1080 で1コマずつ画像を保存する

  （タイトルの文字も画像に描き込む）。ffmpeg で音とロゴをつないで MP4 にする。

【進め方】

  - 場面ごとに画面を見て崩れやエラーがないか確認する

  - 白飛び・暗すぎ・文字と船の重なりがあれば直してから書き出す
```
