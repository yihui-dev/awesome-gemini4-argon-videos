## Prompt

```text
Create a **single self-contained HTML file** using **Three.js** that renders a highly realistic, cinematic black hole inspired by **Gargantua from Interstellar**.

Prioritize visual realism over UI complexity. The black hole should have:
A deep black event horizon
Strong gravitational lensing that visibly bends the accretion disk around the black hole
A bright photon ring near the event horizon
A thin, detailed accretion disk with turbulent glowing material
The characteristic lensed disk appearing both above and below/behind the black hole
Relativistic Doppler beaming: one side brighter/bluer and the opposite side dimmer/redder
Bloom, HDR-like highlights, subtle noise, and a realistic star field
Smooth animation of the accretion material without looking like a simple rotating texture

Use shaders wherever necessary rather than relying only on standard Three.js materials.

Add a clean, compact floating control panel with real-time sliders for:
Black hole mass / apparent size
Spin
Gravitational lensing strength
Photon ring intensity
Accretion disk inner radius
Accretion disk outer radius
Disk thickness
Disk brightness
Disk temperature/color
Doppler / relativistic effect strength
Disk rotation speed
Turbulence
Bloom intensity
Exposure
Camera distance
Camera inclination/viewing angle
Star-field brightness

Changes should update immediately while dragging the sliders.

Allow mouse/touch orbiting and zooming, but keep the initial camera angle composed like a cinematic Interstellar-style shot.

Keep the interface minimal and dark so the black hole remains the focus. Include **Reset to Default**, **Pause Animation**, and **Hide Controls** buttons.

Everything must run directly from the one HTML file with no build process. Make the simulation visually convincing first; don't add unrelated features, explanatory sections, menus, or unnecessary UI.

Before finishing, test the rendering, controls, resizing, animation performance, and shader compilation errors. Aim for the closest practical approximation of a physically plausible Interstellar-style black hole achievable in real-time WebGL.
```
